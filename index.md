# Patient Event Sequencing

The Patient Event Sequencing module computes the days between two
user-specified events and summarizes the distribution within the cohort.
This module allows investigators to evalute the plausibility of the
sequential relationship between two events and identify outliers in the
cohort where the events may be too close together or far apart.

## Installation

You can install the development version of this package like so:

``` r
devtools::install_github('ssdqa/patienteventsequencing')
```
