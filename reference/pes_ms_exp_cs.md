# *Multi-Site, Exploratory, Cross-Sectional*

*Multi-Site, Exploratory, Cross-Sectional*

## Usage

``` r
pes_ms_exp_cs(process_output, large_n = FALSE, large_n_sites = NULL)
```

## Arguments

- process_output:

  output generated by the `pes_process` function

- large_n:

  a boolean indicating whether the large N visualization, intended for a
  high volume of sites, should be used; defaults to FALSE

- large_n_sites:

  a vector of site names that can optionally generate a filtered
  visualization

## Value

a bar graph representing the proportion of patients at each site that
meet a set of thresholds: 30 days, 60 days, 90 days, one year, and the
user provided threshold value

        dotted line represents the all site median
