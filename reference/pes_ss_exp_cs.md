# *Single Site, Exploratory, Cross-Sectional*

*Single Site, Exploratory, Cross-Sectional*

## Usage

``` r
pes_ss_exp_cs(process_output)
```

## Arguments

- process_output:

  output generated by the `pes_process` function

## Value

a patchworked object with a histogram showing the distribution of days
between events with a line representing the median number of days and a
bar graph representing the proportion of patients excluded from the
histogram because they did not have evidence of event b

a bar graph representing the proportion of patients that meet a set of
thresholds: 30 days, 60 days, 90 days, one year, and the user provided
threshold value
